# smartclass-buct（`scls`）项目文档

> 版本：2026-10-19（包含并发提速、扁平目录、`migrate-layout`）
> 适用平台：北京化工大学 smartclass（`buct.smartclass.cn`）
> 用途：处理**本人有权限访问**的课程录播，供个人复习；不提供代登录、代填验证码、绕过权限等能力。

## 1. 项目是什么

`scls` 是一个 Windows 命令行工具。你给它「日期（或日期区间）+ 课程名」，它会：

1. 登录态复用浏览器 profile（登录由你手工完成一次）；
2. 从平台列表里找出这些课的**小节**，按「整课」合并；
3. 下载课件机位视频（默认只下 `vga` 屏幕机位）；
4. 抽音频 → 分块语音转写（本地 OpenAI 兼容网关，默认 Gemini）；
5. 抽帧 → 课件 OCR（只抄作业相关内容）；
6. 合并成整课转写 / 整课课件文字；
7. 归纳出 **`homework_<日期>_<时段>.md`**（作业要求 + 证据区）与
   **`notes_<日期>_<时段>.md`**（课堂笔记）；
8. 按策略压缩视频（默认 1080p / CRF 33 / veryfast）。

一句话：**一条命令，把一节课变成可复习的视频 + 转写 + 作业清单 + 笔记。**

它不是：

- 不是通用录屏下载器（只处理当前账号有权限的课程）；
- 不会保存你的账号密码；
- 不会自动过验证码；
- 不保证 100% 转写准确，归纳结果需要对照「证据区」核对。

## 2. 核心概念

### 2.1 小节（Session）

平台把一次课切成 2~3 个 45 分钟的小节，例如：

```
线性代数A  08:00-08:45
线性代数A  08:50-09:35
```

每个小节在平台上是一条独立录播，有自己的 `NewID` 和播放页。

### 2.2 整课（Lecture）

工具按「**同一门课、同一天、相邻小节间隔 ≤ 30 分钟**」把小节合并成一节**整课**。
整课才是产出单位：转写、作业要求、笔记都按整课生成，不会被小节切断。

阈值可配：

```toml
[grouping]
max_gap_minutes = 30
```

`scls list` 会直接打印分组结果，方便核对。

### 2.3 唯一标识符（uid）

每个整课有一个 uid，格式：

```
<日期>_<整课时段>
2026-10-16_0800-1030
```

每个小节（part）也有自己的 uid：

```
<日期>_<小节时段>
2026-10-16_0800-0845
```

uid 用在文件名里，保证把 `homework` / `notes` 单独拷出来后仍能区分是哪天哪节。

### 2.4 切片粒度

```bash
scls run --course 化工导论 --unit lecture   # 默认：整课一份
scls run --course 化工导论 --unit session   # 每个小节各一份
scls run --course 化工导论 --unit both      # 两者都要
```

- `lecture`：只产出整课级 `homework_<日期>_<整课时段>.md` / `notes_...`。
- `session`：只产出小节级 `parts/<时段>/homework_<日期>_<小节时段>.md` / `notes_...`。
- `both`：两套都产出。

## 3. 环境与安装

### 3.1 依赖

| 依赖 | 要求 | 用途 |
|---|---|---|
| Windows | 10/11 | 计划任务、路径、通知 |
| Python | ≥ 3.11 | `tomllib`、类型语法 |
| ffmpeg / ffprobe | 在 PATH 里 | 抽音频、切块、抽帧、压缩、校验 |
| Playwright Chromium | 首次安装 | 复用登录态、发现课时、取流 |
| Pillow | ≥ 10（随包安装） | 抽帧 dHash 去重 |
| 本地网关 | OpenAI 兼容 | 转写 / OCR / 归纳 |

### 3.2 安装

```powershell
cd "C:\Users\USER\Desktop\资料\smartclass-buct"
python -m pip install -e .
python -m playwright install chromium
```

安装后会有 `scls` 命令。验证：

```powershell
scls --help
```

### 3.3 本地网关

默认配置：

```toml
[asr]
gateway_url = "http://127.0.0.1:8317/v1/chat/completions"
gateway_key = "123456"
```

网关需要支持：

- `POST /v1/chat/completions`
- `messages[].content[]` 里的 `input_audio`（mp3，base64）
- `image_url`（jpeg，data URI）
- 普通文本 chat

默认模型：

| 阶段 | 模型 | 说明 |
|---|---|---|
| ASR | `gemini-3-flash` | 快；10 分钟块约 7~13 秒 |
| 课件 OCR | `gemini-3.8-flash-high` | 慢一些，课件文字更稳 |
| 归纳 | `gemini-3.8-flash-high` | 作业/笔记质量优先 |

可用 `scls bench` 测你本地网关的实际并发与模型速度，见第 10 节。

> 网关端口/模型以你本地 cc-switch 的实际配置为准；`smartclass.toml` 里改
> `gateway_url` / `gateway_key` 即可。不要提交这个文件。

## 4. 首次配置

### 4.1 配置文件位置

按以下顺序找，**找到第一个就用**：

1. 命令行 `--config <path>`
2. 环境变量 `SCLS_CONFIG`
3. 当前目录 `./smartclass.toml`
4. 仓库根目录 `smartclass-buct/smartclass.toml`（推荐）
5. `~/.smartclass-buct.toml`（旧位置，兼容）

模板在 `config.example.toml`。复制成 `smartclass.toml` 后修改。
`smartclass.toml` 含本地网关口令，已在 `.gitignore` 里排除，**不要提交**。

### 4.2 最小配置

```toml
[site]
base_url = "https://buct.smartclass.cn"
profile_dir = "C:\\Users\\USER\\Desktop\\资料\\smartclass-buct\\data\\_profile"

[paths]
runs_root = "C:\\Users\\USER\\Desktop\\资料\\smartclass-buct\\data"
ffmpeg = "ffmpeg"
ffprobe = "ffprobe"

[asr]
gateway_url = "http://127.0.0.1:8317/v1/chat/completions"
gateway_key = "你的本地网关口令"
```

### 4.3 完整配置参考

#### `[site]`

| 字段 | 默认 | 说明 |
|---|---|---|
| `base_url` | `https://buct.smartclass.cn` | 平台地址 |
| `profile_dir` | `~/.smartclass-buct/profile` | Chrome user-data-dir，保存登录态 |
| `login_timeout` | `300` | 等待手工登录的秒数 |
| `storage_state` | `""` | 可选：导出的 Playwright storage state 文件，启动时注入 cookie + localStorage |

#### `[paths]`

| 字段 | 默认 | 说明 |
|---|---|---|
| `runs_root` | `~/smartclass-buct/runs` | 产出根目录 |
| `ffmpeg` | `ffmpeg` | ffmpeg 可执行文件 |
| `ffprobe` | `ffprobe` | ffprobe 可执行文件 |

#### `[grouping]`

| 字段 | 默认 | 说明 |
|---|---|---|
| `max_gap_minutes` | `30` | 相邻小节间隔 ≤ 此值就并成整课 |

#### `[retention]`

| 字段 | 默认 | 说明 |
|---|---|---|
| `keep_video` | `compressed` | `none` / `compressed` / `original` |
| `video_height` | `1080` | 源高于此值才缩放 |
| `video_crf` | `33` | 统一质量参数：x264 的 CRF；QSV 自动映射 `global_quality = crf - 3` |
| `video_preset` | `veryfast` | 编码预设（各编码器自动映射等价档位） |
| `video_codec` | `libx264` | 仅 CPU 编码时使用 |
| `video_encoder` | `auto` | `auto`=探测 QSV→NVENC→AMF 后回退 CPU；也可强制 `cpu`/`qsv`/`nvenc`/`amf` |
| `video_fps` | `0` | 0=保持源帧率；10/5 可显著加快编码 |
| `skip_below_kbps` | `600` | 码率低于此值不再压 |

#### `[asr]`

| 字段 | 默认 | 说明 |
|---|---|---|
| `provider` | `gateway` | `gateway` / `whisper` |
| `gateway_url` | `http://127.0.0.1:8317/v1/chat/completions` | 本地网关 |
| `gateway_key` | `123456` | 本地网关口令 |
| `model` | `gemini-3-flash` | 主转写模型 |
| `fallback_models` | `[...]` | 主模型空结果/失败时逐个回退 |
| `min_split_seconds` | `45` | 对半切分重试的最小长度 |
| `chunk_seconds` | `600` | 音频块长度 |
| `bitrate` | `32k` | 抽音频码率 |
| `max_tokens` | `8000` | 单块转写上限 |
| `whisper_model` | `small` | `--asr whisper` 时使用 |
| `whisper_bin` | `whisper` | whisper 可执行文件 |

#### `[vision]`

| 字段 | 默认 | 说明 |
|---|---|---|
| `interval_seconds` | `45` | 抽帧间隔 |
| `width` | `1280` | 抽帧宽度 |
| `batch` | `8` | 每次 OCR 送几张图 |
| `model` | `gemini-3.8-flash-high` | OCR 模型 |
| `max_tokens` | `4000` | 单批 OCR 上限 |
| `dedupe` | `true` | 去掉几乎没变化的相邻帧 |
| `dedupe_threshold` | `3` | 256 bit dHash 汉明距离阈值 |

#### `[digest]`

| 字段 | 默认 | 说明 |
|---|---|---|
| `model` | `gemini-3.8-flash-high` | 作业/笔记归纳模型 |
| `max_tokens` | `8000` | 归纳输出上限 |

#### `[concurrency]`

| 字段 | 默认 | 说明 |
|---|---|---|
| `gateway` | `4` | 同时发往网关的请求数（ASR 块 / OCR 批） |
| `downloads` | `3` | 同一小节多机位并发下载数 |
| `compress` | `1` | 后台压缩线程数 |
| `pipeline` | `true` | 处理第 N 节时同时下载第 N+1 节 |

#### `[watch]` / `[schedule]`

| 字段 | 默认 | 说明 |
|---|---|---|
| `watch.courses` | `[]` | `scls daily` 只处理这些课；留空=当天全部 |
| `schedule.time` | `22:30` | 计划任务执行时间 |
| `schedule.task_name` | `smartclass-buct-daily` | Windows 任务名 |

## 6. 命令参考

### 6.1 `scls login`

```powershell
scls login
```

- 有头启动浏览器，打开平台首页。
- 你手工完成登录（账号密码、验证码、统一身份认证都由你操作）。
- 登录态写入 `profile_dir`，后续命令复用。
- 不会代填任何凭据。

### 6.2 `scls list`

```powershell
scls list --date 2026-10-12
scls list --from 2026-09-01 --to 2026-10-16 --course "物理化学(Ⅰ)"
scls list --date 2026-10-12 --time-from 08:00 --time-to 12:00
scls list --date 2026-10-12 --weekday mon,wed,fri
scls list --date 2026-10-12 --gap 20
```

只发现、不下载、不处理，按整课分组打印。

| 参数 | 说明 |
|---|---|
| `--date D` | 单日 |
| `--from D1 --to D2` | 日期区间（与 `--date` 互斥） |
| `--course NAME` | 课程名模糊匹配 |
| `--time-from HH:MM` | 只要开始时间不早于此的课 |
| `--time-to HH:MM` | 只要开始时间不晚于此的课 |
| `--weekday mon,wed` | 按星期过滤 |
| `--gap MIN` | 覆盖整课合并阈值 |
| `--headed` | 有头运行，登录失效时可现场登录 |

> 区间查询会翻页拉全，日志会打印「翻页完成：… 共 N 条，实收 N 条」。
> 如果区间内某个工作日完全没有录播（放假/停课/录制失败），日志会显式列出这些日期。

### 6.3 `scls run`

```powershell
scls run --course 化工导论 --date 2026-10-12
scls run --course "物理化学(Ⅰ)" --from 2026-09-01 --to 2026-10-16 --unit lecture
scls run --course 化工导论 --date 2026-10-12 --dry-run
```

完整流水线：发现 → 取流 → 下载 → 转写 → OCR → 合并 → 归纳 → 压缩。

| 参数 | 说明 |
|---|---|
| `--unit lecture\|session\|both` | 切片粒度（默认 `lecture`） |
| `--tracks vga,video1` | 机位；默认只下 `vga`（课件屏幕） |
| `--out DIR` | 输出根目录 |
| `--asr gateway\|whisper` | 转写通道 |
| `--keep-video none\|compressed\|original` | 视频策略 |
| `--jobs N` | 临时覆盖网关并发 |
| `--force` | 忽略缓存，全部重跑（**会重新下载视频**） |
| `--dry-run` | 只发现 + 取流并打印机位地址/体积 |
| `--no-slides` | 跳过课件 OCR |
| `--no-digest` | 跳过作业/笔记 |
| `--headed` | 有头运行 |

> `--dry-run` 只取流、不下载，适合先确认当天有没有录播。
> `--force` 注意：它会重新下载已有视频。只想重跑转写/OCR，用 `scls resume --force`。

### 6.4 `scls resume`

```powershell
scls resume --dir "data/物理化学(Ⅰ)"
scls resume --dir "data/物理化学(Ⅰ)/2026-09-04"
scls resume --dir "data/物理化学(Ⅰ)/2026-09-04" --force --keep-video original
```

**不联网、不登录、不下载**，直接读本地整课包续跑转写/OCR/归纳/压缩。
已完成的块会跳过；`--force` 只重跑本地处理，不会下载。

适用于：下载完成但处理中断、想换模型重跑、想补 OCR。

### 6.5 `scls daily`

```powershell
scls daily
scls daily --date 2026-10-12
```

无人值守：处理当天（或指定日期）`[watch] courses` 里所有课的整课。
也是计划任务实际执行的命令。

- 日志：`data/_logs/<日期>_daily.log`
- 登录失效：退出码 `2`，写 `data/_state/login-needed.txt`，弹 Windows 通知。
- 不会自动登录；失效后手工 `scls login`。

### 6.6 `scls bench`

```powershell
scls bench --run "data/物理化学(Ⅰ)/2026-10-16/parts/0800-0845" \
           --stage asr,ocr --concurrency 1,2,4,6
```

用已经缓存的 `audio/chunks/*.mp3` 与 `frames/*.jpg` 测网关：

- 每个「模型 × 并发度」的墙钟时间；
- 单请求平均耗时；
- 输出字数；
- 与现有转写的相似度（仅参考）；
- 空结果次数。

**不覆盖任何转写缓存**。结果写入 `data/_logs/bench-<时间>.json`。

### 6.7 `scls regroup`

```powershell
scls regroup
```

把第一阶段的小节目录（`<日期>/<时段>/meta.json`）原地合并成整课包，
再生成/更新整课级转写、课件文字、作业/笔记。**不重新下载**。
已有整课包会跳过；幂等。

### 6.8 `scls migrate-layout`

```powershell
scls migrate-layout --dry-run
scls migrate-layout
```

把旧布局 `data/<课程>/<日期>/<时段>/` 扁平化为 `data/<课程>/<日期>/`：

- `homework.md` → `homework_<日期>_<时段>.md`
- `notes.md` → `notes_<日期>_<时段>.md`
- 小节级 `parts/<时段>/homework.md` / `notes.md` 同样改名
- `transcript.txt` / `slides.txt` / `lecture.json` / `parts/` 上移

同一天有多节整课时，第一节保留无后缀的 `transcript/slides/lecture.json`，
后续自动加 `_<日期>_<时段>` 后缀。**幂等**，可以反复跑。

### 6.9 `scls prune`

```powershell
scls prune --keep-video compressed
scls prune --keep-video none
scls prune --force
```

对已有数据补做视频压缩/删除。`--force` 会重做已标记处理过的视频。
会跳过 `_state` / `_profile` / `_手工初版` 等归档目录。

### 6.10 `scls schedule`

```powershell
scls schedule install
scls schedule install --time 22:30 --task-name smartclass-buct-daily
scls schedule show
scls schedule remove
```

用 Windows `schtasks` 创建/查询/删除每日任务。实际执行的是
`data/_state/run-daily.cmd`，它 `cd` 到仓库根目录并运行 `scls daily`，
日志追加到 `data/_logs/schtasks.log`。

> 计划任务只在**已登录的桌面会话**里触发；睡眠/关机时不跑。

### 6.11 `scls asr` / `scls slides` / `scls digest`

```powershell
scls asr    --run "data/物理化学(Ⅰ)/2026-10-16" --force
scls slides --run "data/物理化学(Ⅰ)/2026-10-16" --mode assignment --force
scls digest --run "data/物理化学(Ⅰ)/2026-10-16" --force
scls digest --run "data/物理化学(Ⅰ)/2026-10-16" --no-notes
```

对已有目录分阶段重跑，幂等：

- `asr`：重新转写（默认复用 `part_NNN.json`）
- `slides`：重新抽帧 + OCR（默认复用 `slides.txt`）
- `digest`：重新归纳（默认复用 `homework_*.md` / `notes_*.md`）

`--run` 可以是整课目录（日期目录）、数据根目录或小节目录。

### 6.12 退出码

| 退出码 | 含义 |
|---|---|
| `0` | 成功 |
| `1` | 一般错误（没有课时、处理失败等） |
| `2` | `daily` 登录失效，需要 `scls login` |
| `3` | 已有另一个 `scls` 在跑（文件锁） |
| `130` | 用户 Ctrl+C |

## 7. 目录与产物

### 7.1 数据根目录

```
data/
├── <课程>/<日期>/          ← 整课包（扁平）
├── _手工初版/              早期手工整理的留档（不参与自动处理）
├── _profile/               浏览器登录态
├── _logs/                  每日日志、bench 报告、schtasks.log
└── _state/                 锁、登录失效留痕、计划任务包装脚本、迁移备份
```

### 7.2 整课包

```
data/<课程>/<日期>/
├── homework_<日期>_<时段>.md   作业要求汇总
├── notes_<日期>_<时段>.md      课堂笔记
├── transcript.txt              整课逐字转写
├── slides.txt                  整课课件 OCR
├── lecture.json                整课元数据
└── parts/<小节时段>/
    ├── meta.json               小节元数据
    ├── videos/                 视频（压缩后就地替换）
    ├── audio/                  抽出的 mp3 + chunks/
    ├── transcript/             part_NNN.json + full.txt
    ├── frames/                 抽帧 jpg
    ├── slides.txt              小节课件 OCR
    ├── homework_<日期>_<时段>.md  小节级作业（--unit session 时）
    └── notes_<日期>_<时段>.md     小节级笔记
```

### 7.3 `lecture.json`

```json
{
```

## 8. 筛选与切片

### 8.1 日期

```powershell
scls list --date 2026-10-12
scls list --from 2026-09-01 --to 2026-10-16
```

`--date` 与 `--from/--to` **互斥**，同时给会直接报错，不会静默只查一天。

### 8.2 时段与星期

```powershell
scls list --date 2026-10-12 --time-from 08:00 --time-to 12:00
scls list --date 2026-10-12 --weekday mon,wed,fri
```

筛选作用在**小节**上，再做整课合并。所以 `--time-to 10:00` 会把 10:40 的小节切掉，
整课就只剩 09:45-10:30。

### 8.3 课程名容错

以下写法都能匹配同一门课：

```
物理化学(Ⅰ)
物理化学(I)
物理化学（Ⅰ）
物理化学
```

罗马数字、全角括号、空格、大小写都会折叠。目录名一律取平台返回的课程名，
不会因为输入法不同生成两个目录。

### 8.4 PowerShell 引号

课程名带括号时**必须加引号**：

```powershell
scls run --course "物理化学(Ⅰ)" --date 2026-10-16   # 正确
scls run --course 物理化学(Ⅰ) --date 2026-10-16     # ✗ PowerShell 报错
```

## 9. 视频策略

| 策略 | 行为 | 体积 |
|---|---|---|
| `compressed`（默认） | 1080p 保分辨率重编码，就地替换。默认走 GPU（QSV/NVENC/AMF 自动探测），不可用则 CPU x264 | 737MB → 128MB（GPU 实测） |
| `none` | 处理完删除原视频，只留 mp3 + 关键帧 + 文本 | 一小节约 20MB |
| `original` | 不动原件 | 741MB/小节 |

安全闸：

- 压缩后先 `ffprobe` 校验时长；
- 时长偏差超过 8%（且 >5 秒）→ **保留原文件**并回报原因；
- 码率已低于 600 kbps → 不再压，避免二次损失画质；
- 硬件编码失败 → 本进程内自动回退 CPU 重试，不中断整批任务。

GPU 编码实测（Intel Arc B390）：45 分钟 1080p 小节 **47~51 秒**（x264 约 104 秒），
CPU 占用几乎归零，与 OCR/归纳不抢核。产物加 `-movflags +faststart`，Web 播放可拖进度条。

想更快可以设 `[retention] video_fps = 10`（编码快 2~3 倍，画面仍是 1080p）。

## 10. 性能与并发

默认配置下，一批 5 节整课（15 个小节）约 **20~25 分钟**；
改造前约 **100 分钟**。单节整课实测 **146 秒**（不含压缩）。

主要手段：

| 手段 | 效果 |
|---|---|
| ASR 块并发 | 5 块/小节同时跑，168s → 40~50s |
| OCR 批并发 | 9 批同时跑，88s → 20~30s |
| ASR 与抽帧/OCR 并行 | 抽帧的几十秒解码藏在转写等待里 |
| 压缩后台化 | 与下一小节重叠，不再堆在每节最后 |
| 下载并发 + 流水线 | 处理第 N 节时下载第 N+1 节 |
| 抽帧去重 | 平均省约 27% 的 OCR 请求 |
| 换快模型 | `gemini-3-flash` 比 `flash-high` 快 4~5 倍 |

调优：

```powershell
scls bench --run "<某个已缓存小节>" --stage asr,ocr --concurrency 1,2,4,6
```

- 并发 2 通常就能吃满 `gemini-3-flash`；
- 日志出现「被限流」→ 把 `[concurrency] gateway` 降到 2；
- 想完全退回串行：`gateway=1, downloads=1, compress=1, pipeline=false`。

## 11. 定时任务

```toml
[watch]
courses = ["化工导论", "线性代数A"]   # 留空 = 当天全部

[schedule]
time = "22:30"
task_name = "smartclass-buct-daily"
```

```powershell
scls daily                    # 手动跑一次
scls schedule install         # 装成每天 22:30
scls schedule show
scls schedule remove
```

- 日志：`data/_logs/<日期>_daily.log`；计划任务另有一份 `schtasks.log`。
- 登录失效：退出码 `2`，写 `data/_state/login-needed.txt`，弹通知。
- 文件锁：`data/_state/run.lock`，同一时刻只允许一个抓取进程。
- 计划任务只在已登录的桌面会话触发，睡眠/关机不跑。

## 12. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `登录已失效，请先运行 scls login` | 平台会话过期 | 运行 `scls login`，手工登录 |
| `转写网关不可用` | 本地 cc-switch / 网关没启动，或端口不对 | 启动网关；核对 `[asr] gateway_url` |
| `错误：网关转写失败（part_xxx.mp3）：HTTP 429` | 并发太高被限流 | 把 `[concurrency] gateway` 降到 2 |
| `模型返回空结果（choices 为空）` | 某些音频模型不返回 | 工具会自动换 fallback 模型/对半切；仍失败就换 `[asr] model` |
| `HEAD 失败：SSLError ...` | VOD 主机偶发 SSL 抖动 | 工具会重试 3 次；已下载的视频会本地优先，不再取流 |
| `2026-xx-xx 没有课时` | 当天没课/放假/录制失败 | 用 `scls list --date` 核对；日志会提示空白工作日 |
| `翻页后仍未取到 … 课时` | 列表接口改版或登录态异常 | 先 `scls list --date` 单日核对；重新登录 |
| PowerShell `CommandNotFoundException` | 课程名括号没加引号 | 用 `"物理化学(Ⅰ)"` |
| `已有 scls 在运行（pid …）` | 文件锁 | 等它结束；确认没在跑后删 `data/_state/run.lock` |
| 计划任务没跑 | 睡眠/关机/未登录桌面 | 保持登录会话；或手动 `scls daily` |
| 视频被压得太糊 | `crf`/`video_fps` 太激进 | 提高 `video_crf` 或设 `video_fps=0`，用 `--keep-video original` 重下 |

### 12.1 下载完成但处理中断

```powershell
scls resume --dir "data/物理化学(Ⅰ)"
scls resume --dir "data/物理化学(Ⅰ)/2026-09-04" --force
```

`resume` 不联网，直接读 `lecture.json` 与 `parts/*/videos/*.mp4`，
转写/OCR 按块缓存续跑。

### 12.2 旧目录迁移

```powershell
scls migrate-layout --dry-run
scls migrate-layout
```

迁移是幂等的；已迁移的目录会被跳过。

## 13. FAQ

**Q：工具会自动填账号密码或验证码吗？**
不会。`scls login` 只打开浏览器，登录完全由你手工完成。

**Q：为什么转写有错字/漏句？**
语音识别是概率模型。工具已经做了模型回退、对半切分、文本清理；
关键结论请对照 `homework_*.md` 末尾的「证据区」原文行。

**Q：为什么某天没有录播？**
可能是放假、停课、老师没录、或录制失败。平台不会返回这类记录；
日志会把区间内「工作日却没有任何录播」的日期列出来。

**Q：能只要作业、不要视频吗？**
可以：`--keep-video none` 处理完删除视频，只留音频/关键帧/文本；
或者 `--no-slides` / `--no-digest` 跳过对应阶段。

**Q：能换模型吗？**
可以。`[asr] model`、`[asr] fallback_models`、`[vision] model`、`[digest] model`
都可以改。换完建议跑一次 `scls bench`。

**Q：数据能搬到别的机器吗？**
可以。整个 `data/<课程>/` 目录拷走即可；`_profile` 不要跨机器复用（登录态绑定环境）。
换机器后在新机器上 `scls login`。

**Q：会占多少磁盘？**
默认压缩后一个小节约 50~100MB，一节整课（2~3 小节）约 150~250MB；
15 个小节约 1~1.5GB。原始视频约 741MB/小节，处理完会被压缩替换。
`keep_video=none` 更省。

**Q：为什么同一天同一门课有两个 `transcript_...`？**
一天有两节不连续的整课（如上午+下午）。第一节用无后缀文件，第二节自动加
`_<日期>_<时段>` 后缀，避免覆盖。

## 14. 已知限制

- 登录会过期，需要定期 `scls login`；定时任务不是完全无人值守。
- 列表接口/页面结构若改版，`discover` 可能拉不全；日志会警告。
- 并发上限取决于本地网关和上游账号；可能触发 429。
- 抽帧去重会合并「停留 <45 秒且画面几乎相同」的相邻幻灯片；需要绝对完整时设
  `[vision] dedupe = false`。
- `--asr whisper` 在无 GPU 机器上非常慢，仅作断网兜底。
- `libx265` 更小但慢约 3 倍，默认 `libx264`。
- 平台自带语音识别对多数录播为空，所以必须自建转写；转写质量取决于网关模型。

## 15. 合规与隐私

- 仅用于处理本人账号有权限访问的课程录播，供个人复习。
- 不提供代登录、代填验证码、绕过权限、批量抓取他人课程等能力。
- `smartclass.toml` 含本地网关口令，已在 `.gitignore` 中排除。
- `data/` 全部产出不入库；`_profile/` 是浏览器登录态，注意不要外传。
- 转写/OCR/归纳会把课程音频、课件截图发送到你配置的**本地网关**；
  如果网关转发到云端模型，请自行确认其隐私政策。
